# 가상 조닝 예제 8종

모든 형상은 새로 만든 연습용 입력이며 실제 프로젝트 도면이 아닙니다. 각 폴더의 input.dxf, input.json, preview.svg, expected.md를 함께 확인합니다. 도면별 실제 검증 결과는 포함하지 않습니다.

01-approximate: 대략 조닝. 02-centerline: 중심선. 03-finish-face: 마감선. 04-missing-name: 실명 없음. 05-duplicate-name: 이름 중복. 06-open-boundary: 열린 경계. 07-overlap: 겹침. 08-centimeter: cm→mm 정규화.

벽 두께와 치수는 예제에만 적용됩니다. 구조·현관·문창·설비 조건은 새 작업에서 확인합니다. 파일을 별도 도면으로 열고 JSON의 단위/경계 의미와 알려진 길이를 대조하세요.
