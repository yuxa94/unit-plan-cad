# 입력: CAD 경계 또는 HTML 조닝

닫힌 실 폴리라인과 실명 TEXT/MTEXT를 대응합니다. 단위·알려진 길이·외곽·좌표계·고정 요소·현관·경계 의미(대략 조닝/벽 중심선/마감선)를 기록합니다. 열린/자기 교차 경계, 이름 누락/중복, 겹침/틈을 확인합니다. 원호 bulge는 직선으로 임의 대체하지 않습니다.

## HTML editor 1.1

[편집기](../assets/examples/zoning-editor/index.html)는 실 사각형, 8개 조절점, 앞뒤 순서, 되돌리기, JSON/DXF 저장을 지원합니다.

- editor.rooms는 뒤→앞 순서의 편집용 원본 사각형입니다. 마지막 실이 겹친 부분을 차지합니다.
- room_regions의 각 outer minus holes가 최종 유효 영역입니다. 원본 사각형을 최종 CAD 경계로 다시 사용하지 마세요.
- 여러 조각은 room_id로 같은 실에 연결합니다. 완전히 가려진 실은 편집 데이터에는 남지만 최종 형상이 없습니다.
- entities에는 ZONE_ROOM 외곽, ZONE_HOLE 내부 구멍과 내부 실명 위치가 있습니다.
- DXF의 UNIT_ZONING XDATA는 경계/실/구멍 연결 정보를 보존합니다. 일반 DXF 원의 모양만으로 구멍 관계를 추측하지 마세요.
- 1.0은 legacy 입력으로 읽고 겹침이 있다면 선택할 해석안을 준비합니다.

편집기 표시 면적은 조닝 면적입니다. 마감 후 유효면적이나 법정 면적으로 표시하지 않습니다. 조닝을 벽 기준면으로 바꾸는 판단은 별도 기록합니다.
