# 상세 작성 규칙

프로젝트별 수치·스타일은 사용자 로컬 프로파일에서 읽습니다. 공통 기본 벽 두께, 창호 높이 또는 FL/SL은 제공하지 않습니다.

- 벽: 코어와 양측 마감/단열을 구분하고 기준면·T/L 접합·단차·개구부 리턴을 기록합니다. 공유 벽을 중복 생성하지 않습니다.
- 단열: 물리적 띠, 실제 두께, 코너 연속성과 개구부 양 끝의 끊김을 확인합니다. 기호 축척을 공칭 두께로 해석하지 않습니다.
- 해치: 재료별 폐합 경계와 내부 구멍을 사용합니다. 패턴·각도·유효 축척·면적을 실제 참조와 비교합니다.
- 문창: 프레임/문짝/벽개구부/유효폭/제품공칭치수를 분리합니다. 실제 기준점, 경첩과 로컬 내외부 방향을 측정하고 원척으로 배치합니다. 필요한 규격이 없으면 검토 후보를 새로 작성합니다.
- 주석: 실명·레벨·상자·기호를 의미 있는 그룹으로 관리합니다. 승인한 스케줄에서 내용과 태그를 재생성하고 부품의 고정 TEXT 잔존을 검사합니다.
- 치수: 전체/분할/개구부/마감 치수의 기준점을 저장합니다. 실제 객체 override, 측정값, 표기값, 분할합을 대조합니다. 스타일 이름만으로 축척을 결정하지 않습니다.
- 시트: 기본형/확장형과 해당 설비·문턱·샤프트의 적용을 확인합니다. 모델 테두리가 배치/용지/인쇄축척 설정을 뜻하지 않습니다.

검토는 객체 존재 확인에서 끝나지 않습니다. [벤치마크](benchmark.md)에 해당 상세의 실제 근거를 연결합니다.
