# 로컬 참조 재작성 검증

공개판에는 통과한 프로젝트 동등성 시험 결과가 포함되어 있지 않습니다.

대표 참조 평면의 경계·스케줄·부품을 읽고 새로운 DWG에서 재구성합니다. 전체 세대 블록을 삽입한 결과를 조닝 기반 생성의 근거로 사용하지 않습니다. 동일 축척의 전체/상세 화면과 저장본 객체를 비교합니다.

벽/마감, 단열, 해치, 문창, 가구설비, 중심선/치수, 실명/레벨/기호, 시트별로 pass/fail/unresolved를 기록합니다. 기준과 허용오차는 프로젝트 정밀도와 요구에서 정하고 실제 객체·위치·차이·근거를 남깁니다.

geometry, visual_detail, saved_dwg, plot 검증을 분리합니다. 출력 스타일/폰트/배치가 없으면 출력 동등성은 미검증입니다. 연결 성공이나 파일 해시 검사는 이 검증을 대신하지 않습니다. 변경한 규칙/자산에 해당하는 항목은 다시 검사합니다.
